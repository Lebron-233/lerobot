# F-UDI1：已保存更新的梯度与时序归因

2026-09-17。接续BRP1完整阴性，最终目标是可验证的SmolVLA异步推理，而非不断增加开发集训练。
本轮不生成新候选，检验：失败来自当前样本自己的优化步骤，还是其他样本随后改变共享权重；
同时描述token/首动作/chunk三个损失组的梯度关系，以及实际AdamW位移的一阶效应。
不能由描述性梯度夹角单独证明因果，也不把训练诊断包装为闭环或新初态泛化。

## 冻结范围

来源为F-BRP1 e35cfc17已审计的初始权重、72步梯度/更新后权重、控制与最终输出、原开发来源。
全部72原训练样本/18episode按原multi_conditioned顺序纳入，不筛误差；每例只在其原更新前/后权重评价。
原开发混合归档包含16验证条目，加载通用来源时可在CPU出现，但本轮没有验证样本前向、指标比较、选点或优化。
R1资格32样本、task8/9及confirmation均不读，不追加Env或新编码。
预先固定两个训练哨兵(4,46,5)、(5,48,6)，分别代表严重退化和已得收益丢失；它们是有意选取的案例，非代表性随机样本。
每个哨兵覆盖原0..72全部73个检查点，不挑最好步，不导出新的模型。

## 执行与算术

每个训练样本重新加载原更新前权重，以原train模式和可微eager十步decoder、同noise/state/language/动作计算。
raw/BF16残差、完整输出逐值等于原训练归档。一次原组合loss.backward重放，裁剪后梯度与原保存梯度
按既有优化器核验rtol1e-5/atol1e-7比较，norm同容差；不放宽原输出exact。
在同一计算图分别取三组梯度：Lz/Sz；w*La/Sa+relu(La-Ra)/Sa；Lc/Sc+relu(Lc-Rc)/Sc。
Ra/Rc及w/scale均用原BRP训练记录，不新选系数。保存全部向量、范数、夹角与实际保存权重位移的内积。
组件梯度相加可因BF16反向舍入不等于一次组合反传，归一化残差仅描述，不强行声明数学exact或改精度。
加载原更新后权重，在同一样本/eager路径评价，无optimizer.step。全部72例输出以及两个哨兵146点保存。

用固定初始IAR、更新前、更新后、最终BRP输出，重算同一oracle的首动作/50x7D chunk/token/原BRP目标。
E_final-E_initial = (E_before-E_initial)+(E_after-E_before)+(E_final-E_after)，分别称earlier/own/later。
对全部样本报告方向、均值和完整逐例分解。72例每episode均4例，宏平均权重一致。
每个样本的before/after来自不同参数时刻，平均只是路径归因，不是一个新模型的分数。
哨兵报告全部曲线及最大正负跳变对应的真实更新样本。梯度一阶方向不是有限步保证。
不做数据删除、系数搜索、继续训练、线上门选择或新的成功阈值。结果可为任意方向；完整诊断和可定位的错误机制
构成本轮研究信息，不构成部署候选过门。若归因仍不清楚，必须说明，不能继续盲调至阳性。
