# LIBERO 后续实测：视觉编码不是当前推理延迟的主要部分

日期：2026-09-08。

**在本次固定输入、固定模型的 GPU 对照实验中，即使完全省掉当前图像编码，
策略选择仍平均需要 212.260 ms；20/20 次测量均超过 50 ms。**
25/25 组原始路径与复用当前 tokens 路径的归一化动作、反归一化动作均逐元素完全一致。
因此，这次对照没有用动作数值变化换取速度差异。

这是一项算力组成诊断，不是异步控制实验或任务成功率改善。

## 新实验实际执行内容

执行源码：`9699ef2307156918b1b7cae4fa829cb1647a0766`。
[执行前注册](https://github.com/Lebron-233/lerobot/issues/1#issuecomment-5583986019)
在启动前发布一次，并按真实评论 ID 回读。

使用 NVIDIA GeForce RTX 4070 Ti SUPER、既有独立 Python 环境、严格加载的固定
LIBERO checkpoint、原保存处理器与精度、原 50/1/10 生成/消费/去噪合同。
全部参数被冻结；没有训练、编译、换精度、改 chunk、改去噪步数或另装依赖。

输入为两幅确定性的 256×256 坐标渐变图、零位置/夹爪状态和单位四元数，
语言为固定 task 0 字符串。这些是合成形状输入，不是真实机器人观测。
没有创建模拟器或读取数据集、原始 rollout、开发/确认状态。

从正常调用捕获当前图像 tokens。两相机各为 `[1,64,960]`、bf16；对应 mask
为 `[1,64]`、bool。对照只把 `encode_image_tokens` 调用替换成返回这份原始当前 tokens，
其他处理、VLM/prefix、动作专家、去噪与动作选择仍走原路径。它不是未来 tokens，
也不是可用于运动场景的长期图像缓存策略。

共执行 5 组配对 warmup 和 20 组正式配对测量；每组同 seed，交替执行顺序，
每次清空策略及处理器状态；以 CUDA 同步包围总耗时。另测量原视觉编码函数 20 次。
所有结果均保留，没有删去较慢样本或根据结果追加试验。

## 测量结果

下表仅包含预注册的 20 次正式测量。P95 为 20 个样本的经验 nearest-rank 分位数。

| 路径 | 平均 ms | 中位数 ms | 经验 P95 ms | 最小–最大 ms |
|---|---:|---:|---:|---:|
| 完整原始策略选择 | 225.220 | 223.434 | 229.612 | 218.410–264.950 |
| 仅省去当前图像编码 | 212.260 | 210.606 | 219.235 | 206.135–235.432 |
| 单独调用原图像编码 | 10.898 | 10.540 | 12.689 | 10.140–12.769 |

去掉编码后的平均减少量为 **12.960 ms，约 5.75%**，均值速度比约 **1.061×**。
单独编码均值占完整路径均值约 4.84%；它与两次端到端测量的差值不要求完全相等，
因为这些不是同一次调用内的精确时间分解。

即便最快的复用当前 tokens 调用也需 206.135 ms，是 50 ms 的 4.12 倍；
20/20 次均超过该周期。原始与对照路径的归一化、反归一化最大动作差均为 0，
包含 warmup 的 25/25 组全部精确相等。

因此，**仅优化或跳过当前图像编码，不足以让这套未改动的逐步同步 selector 达到
20 Hz。** 这个结论针对测得的固定 fixture 和实现，不是对所有硬件或优化方法的下界。

## 对研究路线的影响

当前有两项相互独立的问题：原生同步任务的逐任务可靠性门槛未过；
完整推理的墙钟耗时也显著超过一个控制周期。后者不能被当作前者的已证实原因。

M3 的目标仍应是预测动作接管时刻的视觉上下文、减少旧观测造成的决策偏差，
而不是把其主要收益描述成省掉昂贵的视觉编码。此次直接测量显示视觉编码占比很小；
大部分耗时位于剩余策略路径，尚未进一步分解为 prefix、动作专家或 CPU 调度的比例。

下一步优先对已关闭任务的失败轨迹做只读诊断，区分抓取、运输、放置及停滞，
并从实际逐步日志提取延迟分布。不把这些资格样本变成新候选的调参集。
只有新的、独立于这些结果的来源依据或具体实现错误，才足以提出新的候选/合同及
独立资格协议；不能直接打开旧确认队列或启动 LIBERO future-latent 训练。

原始 50/1 消费比例为 2%，但不意味着减少预测 chunk 可以线性省掉 98% 的计算，
也不证明改变消费跨度仍保留任务能力。本轮没有做这类变更。
