## 排除不成立的解释

有限越界分量按 xyz/旋转/夹爪顺序为 `[2,4,64,0,0,0,17903]`。
绝大多数是夹爪命令超过 +/-1；原生 Panda 使用其符号及自身积分/限幅。
task 5 全部 20 条轨迹的前六个动作分量均没有越界。
所以不能把 task 5 失败归结为这批数据中发生了六轴命令截断，更不能新增一个夹爪
幅值 clamp 后便声称修复了任务问题。

本次检测到的“大 axis-angle 表示跳变、但 quaternion 物理变化小”事件为零，
没有证据把当前问题归因于姿态表示的分支跳变。此检查只解释现有轨迹，不改变原始
状态表示、处理器或归一化。

全部任务原本同步取当前观测；上述失败阶段不能作为异步陈旧性的因果证据。
也不能把完整 episode 内的夹爪切换次数直接比较成因果效应，因为失败轨迹更长。
