## 2. 条件采样的准确语义

新增独立模块smolvla_prefix_sampling.py；默认不接入旧控制器，未修改src/lerobot或开启生产trained RTC配置。调用仅接受当前观测、独立noise、C和归一化BxCx7前缀，不接收目标后缀、终止标签或未来观测。

每个Euler步：前C行保持干净动作，7D之外25维补零，逐动作流时间0；后缀从原noise按十步1→0积分。C0由新采样器独立做前缀预填充和原Euler，步级调用原scalar denoiser，并与native sample_actions比较，不通过直接返回native完整结果制造等价。缓存仍逐步裁剪回视觉语言前缀。

训练一致性不意味着部署资格：非零C在本轮使用正确专家前缀或固定错配前缀，而非真实队列的旧策略输出。终端有效mask只用于事后评分，不提供给采样器，避免先知式未来终止信息。

两份检查点是原模型上的8张量绝对投影值，不是可相加delta；加载前验证SHA、base policy、data manifest、arm、version、128更新及deployment_ready=false。原始模型与两个检查点各自独立恢复，没有新更新。
