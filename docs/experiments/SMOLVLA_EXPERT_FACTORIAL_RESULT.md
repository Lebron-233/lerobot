## 4. 真正的2×2交互结果

令L为相同正确前缀评价下的误差；前缀训练收益定义为普通减前缀，正数才是改善。检查专家适配是否扩大该收益：I=(L_C-L_D)-(L_A-L_B)。

|主指标|仅投影的前缀训练收益 A-B|专家适配的收益 C-D|收益差 I|
|---|---:|---:|---:|
|suffix|0.007074082248|0.007133658885|+0.000059576637|
|first|-0.001508146115|-0.001679030673|-0.000170884558|

后缀收益仅略扩大，首动作收益反而进一步为负，因此两个指标共同正交互的预定门未通过。不能拿D相对A无条件首动作降低57.748%来代替这个检验；后者同时提供了正确前缀信息，不等于LoRA或微调净收益。

反归一化命令空间也保留不利结果。D正确前缀的suffix/first/short为0.045685573860/0.038636746120/0.021914853055；相对A无条件分别+9.057%/-8.322%/+43.165%。相对B正确前缀分别-0.01312%/-0.05404%/+0.02170%。归一化会改变维度权重，7D混合命令MSE不是末端距离或物理安全指标。

九项固定门中：优于A无条件的两个主指标、正确优于错配这2项通过；优于B正确、C正确、冻结正确、两指标各>=3/4轨迹改善、两指标正交互、命令空间两组非劣这7项未通过。独立技术审计通过，expert_adaptation_followup_supported=false，不晋级、不改选C、不改生产默认。
