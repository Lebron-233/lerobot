A为serialized当前视觉，B为同路径异步无RTC，C为同路径异步guided RTC。A/B/C尽可能相同eager执行与缓存策略，不能让B用Graph而C用eager后将全部差异归为RTC；若需对既有Graph工程基线比较，单独明确标为实现对照。
