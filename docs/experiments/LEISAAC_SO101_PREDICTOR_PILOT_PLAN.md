## Research question and boundaries

Can a newly trained small residual predictor improve future visual tokens over
holding the current tokens, on independently seeded real SO101 simulator
trajectories generated by the task-matched fixed policy? This is an offline
forecasting pilot on actual action-dependent simulation, not a task-success or
realtime predictive-control claim. L4's task failures and L5's timing failures
remain unchanged. No old SO100 predictor weights, old test/cache/B4 samples or
old scientific approval are reused for this new candidate.

The primed L5 identity engineering run executed221 real controls with eight
planned requests and no underflow/inference-deadline miss, then failed the
unchanged control lost-slot criterion. Preserve that result; do not keep blindly
rerunning the same hardware load to obtain a pass. L6 addresses the project's
scientific predictor question in parallel with this documented runtime limitation.

## Fixed training and selection

Reuse `LightweightFutureLatentPredictor`, newly initialized with seed1907:
native observed token_dim, action_dim6, state_dim32, rank64, action_hidden128,
state_hidden64, delay_embedding32, fusion_hidden128, max_cameras2, horizon8,
depthwise1d mixer, **risk_head=false**. Count parameters in the result.

Train20epochs, batch32, AdamW lr0.001/weight_decay0.0001, gradient clipping1.
Loss: masked mean SmoothL1(predictedZ,targetZ) +0.1*masked mean cosine distance.
Delay/timestep examples are shuffled with the fixed training seed; no test access.
Select the checkpoint with lowest aggregate validation SmoothL1, tie earliest.
The identity baseline is Z[t], evaluated on exactly the same valid targets/masks.

After selection is frozen, evaluate **held-out test once**, reporting per-episode
and per-delay SmoothL1/cosine for identity and predictor, sample counts, absolute
errors and relative changes. Negative improvements remain visible. No new risk
threshold, fallback, checkpoint tuning or statistical-significance claim follows
from these two test episodes. A pass for this pilot requires positive aggregate
test SmoothL1 reduction and no hidden omission of adverse delays/episodes; this
does not replace the project's old scientific gates or qualify online deployment.

Artifacts are a new independent L6 directory with source commits, all seeds,

## Pre-test action-consistency probe (fixed before fitting)

Also measure whether latent improvements survive the **frozen action expert**,
without asserting task success. On each held-out episode use anchors t=0,200,400
and d=1,4,8 only, provided the causal sample is valid. Keep language and current
model-ready state fixed. With identical flow noise compare50-action chunks from:
(a) current visual tokens, (b) predicted future tokens, and (c) actual future
visual tokens. The third is an offline visual-oracle reference, not executable
online and not a future-state oracle. Report normalized-action L1 errors against
that reference, paired per-anchor/delay/episode and aggregate. All cases and
negative changes remain; no selection follows this diagnostic.

Residual application follows the production numeric path: float32 addition,
cast back to the observed native token dtype, then score in float32 / pass native
tokens to the action expert. This is fixed before training starts. The probe
uses no future state and no reference action generated from a future observation
as predictor input. It is part of the single frozen held-out evaluation phase,
not a second model-selection opportunity.
