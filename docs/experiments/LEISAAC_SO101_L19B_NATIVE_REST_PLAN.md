# L19b: one last source-defined start, not an initialization search

Prepared while the registered L19 medoid/zero cohort is running; do not modify
its execution source or interpret partial results as eligibility. Execute this
protocol only after all sixteen L19 conditions close and the training-medoid
condition fails its registered >=7/8 native-success / zero-technical criterion.
If L19 qualifies, leave this contingency unexecuted and confirm L19 independently.

L18 identified a source-supported distinction between zero initialization and
published training first states. L19 tests one observed medoid, but that state
can lie on an in-motion demonstration, and setting its position does not
reproduce its velocity/contact history. A second, independently source-defined
option already exists in the adapter and pinned robot specification: native
rest (0, -100, 90, 50, 0, -10) joint degrees. It is a physical reset pose, not
an outcome-selected average or a recorded demonstration trajectory.

This bounded contingency tests ONLY that existing rest configuration on eight
new scenes 20271030--20271037 and policy seeds 3930--3937, once each. No zero
condition is rerun and no comparison with earlier seed cohorts is promoted as
a causal effect. The endpoint is absolute native-task development eligibility:
>=7/8 three-orange-plus-rest successes and zero technical failures. If it fails,
close this source-defined initialization investigation; no additional pose grid,
prompt search, student-test opening or forecasting campaign follows automatically.

Reuse the exact frozen WSAGI candidate, original dataset task string, native
mean/std, synchronous 50-action execution, CPU PhysX / GPU RTX and standard dual
640x480 cameras at simulated 30Hz. No forecaster, oracle, RTC, trajectory replay,
action-selected reset, object movement or forced end-of-task arm return. Thirty
logged hold preparation steps, same-seed reset and measured rest-state check
precede each trajectory. Objects/front camera retain original randomization;
the wrist view changes with the physical arm pose. Continue to native success
or 120 simulated seconds / 3600 actions, retaining all failures at cost 120s.
First-region occupancy is descriptive, never a substitute for native completion.
This is not a real-time deployment qualification or a forecasting-benefit study.

Publish this plan and source after L19 closes and before the first rest run.

condition's source, candidate, true initial state and pre-reset native witness.
