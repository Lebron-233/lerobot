- 验证相对基底仅8/16样本改善、8/16恶化；相对错配为11/16改善、5/16恶化；相对普通为10/16改善、6/16恶化。最坏验证样本(6,48,6)相对基底增加0.031015107562、相对普通增加0.031380126827。
